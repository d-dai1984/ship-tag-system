# 船舶资产电子标签交互原型

交付文件：项目根目录下的 `船舶资产电子标签管理系统-交互原型-v0.1.html`。直接用浏览器打开，可离线分享，无需安装依赖或运行服务器。

## 浏览方法

- 左侧切换全船看板、仓储管理、标签管理、标签状态及系统管理。
- 右侧显示当前页面对应的产品需求原文；右上角“需求对照”可展开或收起。
- 需求条目下的“可点击演示／查看简化演示”会跳转并短暂高亮对应功能，表单类需求直接打开演示窗口；手机端自动收起需求栏。跳转不会自动保存、导出、下发或改变业务数据。
- 左下角“完整产品文档”内嵌完整 v0.1 文档；“查看演示路线”提供推荐操作顺序。
- 本地修改保存在浏览器 localStorage 中，右上角可重置。不同浏览器的修改不共享；发送 HTML 文件不会携带当前浏览器里的修改。

## 可体验的主要操作

- 三层目录浏览、新增、改名与移动，非空目录删除保护。
- 资产新增、编辑、迁移，资产与标签一对一绑定、更换、解绑。
- 标签搜索、筛选、批量选择、跨目录分组、状态 CSV 导出。
- 自定义字段、CSV 校验和资产批量新增／更新。
- 文本模板预览、标题颜色与字段显隐、复制与应用。
- 条件策略、优先级及刷新计划配置，手动模拟策略匹配。
- 批量下发、模拟成功回执、离线待确认、失败重试及版本变化。
- 网关信息、示例账号权限、参数设置及本地操作日志。

## 原型范围

此文件为沟通原型，示例数据、在线状态和硬件反馈全部模拟，不连接网关或现场标签。

Excel、完整拖拽模板编辑器、图片／二维码／条形码素材编辑、后台定时调度、真实权限与完整异常处理均未实现。需求对照栏保留正式需求原文，并标识简化演示；不能据原型判断厂商能力或生产可用性。

## 后续修改

- `app.js`：页面和交互逻辑、示例数据。
- `styles.css`：浅色界面与响应式排版。
- `shell.html`：应用外壳。
- `build.py`：从当前 Markdown 产品文档提取需求，嵌入样式和脚本，生成单文件 HTML。

在项目根目录运行 `python3 prototype/build.py` 即可重新生成。构建仅使用 Python 标准库。
